INTERACTIVE / PROTOTYPES

Laboratorium algoritma.

Dua mini-aplikasi menjalankan perhitungan sungguhan dengan data sintetis, bukan prediksi atau hasil pengukuran lapangan.

01 / MULTI-CRITERIA ANALYSIS

Simulasi indeks risiko kebakaran

Geser bobot ketiga faktor untuk melihat perubahan skor pada empat sel contoh. Bobot otomatis dinormalisasi.

02 / GRAPH ROUTING

Simulasi rute dan ETA stasiun

Pilih titik awal dan akhir pada graf fiktif. Dijkstra menentukan jarak minimum dan estimasi perjalanan jalan kaki.

Graf A–E sintetis, kecepatan 4 km/jam, tidak terhubung ke API KAI.
