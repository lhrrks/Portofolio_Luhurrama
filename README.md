# LHUR / GEO — Geospatial Portfolio

Portofolio Luhur Ramadani Suryana, D-4 Sistem Informasi Geografis, Universitas Gadjah Mada.

## Fitur
- Website responsif dua bahasa (Indonesia/Inggris).
- Enam studi kasus dengan metode STAR.
- Simulasi pembobotan risiko kebakaran dengan data sintetis.
- Simulasi rute terpendek Dijkstra serta ETA pada jaringan sintetis.
- Filter kategori dan rincian masing-masing proyek.

## Status karya
Dua proyek WebGIS berasal dari dokumentasi praktikum. Analisis risiko kebakaran, routing stasiun, dan aplikasi Android diposisikan sebagai konsep dan prototipe. Demo bukan hasil prediksi risiko ataupun data KAI aktual.
